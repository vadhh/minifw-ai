## Decided
Customer deployment is a native amd64 Debian/Ubuntu gateway installation using the sector-specific .deb generated by scripts/build_deb.sh. Traffic must traverse the gateway for forwarded-packet enforcement. USB Docker kits are documented as demos.
## Tried and ruled out
README alone is insufficient for a customer runbook: systemd/minifw-ai-web.service binds to 127.0.0.1:8443, while install.sh prints a hostname URL. A local .deb does not make installation air-gapped: postinst runs pip against requirements.txt.
## Watch out
scripts/build_deb.sh copies only backup.sh, restore.sh, create_admin.py, and train_mlp.py into the package scripts directory. install.sh subsequently looks for enable_dnsmasq_logging.sh and install_systemd.sh and warns/skips if absent. Verify DNS setup and routed network configuration during commissioning. No deployment was executed for this inspection.
